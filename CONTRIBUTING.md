# Contribuir a VELA

VELA es un proyecto **propietario**. No se aceptan contribuciones externas sin un acuerdo
previo por escrito. Si quieres proponer una idea, un informe de seguridad o una mejora,
abre primero un issue; no envíes un pull request con código hasta que se te indique.

## Código y parches

Para que el titular pueda mantener la licencia propietaria y, si procede, conceder licencias
comerciales, cualquier contribución de código debe ir acompañada de una de estas cosas:

1. **Cesión de derechos** (copyright assignment) al titular, o
2. una **licencia amplia, irrevocable y sublicenciable** que permita al titular usar,
   modificar, distribuir y relicenciar la contribución, incluyendo una licencia comercial.

El texto concreto se acuerda antes de aceptar el PR. Sin ese acuerdo, el PR no se fusiona.

## Informes de seguridad

No publiques vulnerabilidades explotables en un issue público. Usa el medio de contacto
privado del perfil de GitHub o abre un aviso privado de seguridad.

## Terceros

No incluyas código, imágenes, fuentes, datos o assets de terceros sin comprobar y documentar
su licencia. El mapa incorporado es ODbL y no se puede relicenciar como propietario.

## Marcas

Las contribuciones no conceden derechos sobre el nombre o el logo VELA. Ver
[TRADEMARK.md](TRADEMARK.md).
